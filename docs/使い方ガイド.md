## 1. Token Checker とは

**Claude Code** および **Codex（ChatGPT）** のトークン使用率をリアルタイムで確認できるツールです。

- タスクバーのトレイアイコンに残量がひと目でわかるアイコンで表示されます
- 残量が少なくなると自動でアラート通知が届きます
- 普段の作業を邪魔せず、バックグラウンドで動き続けます

```
【イメージ】

タスクバー右下:  [🟢 🟢]  ← Claude と Codex それぞれの残量をドーナツ円で表示
                  緑=余裕あり  オレンジ=注意  赤=残量わずか
```

## 2. 動作環境

| 項目 | 要件 |
|------|------|
| OS | Windows 10 / 11 |
| 必要なツール | Claude Code または Codex のいずれか（または両方） |
| その他 | 上記ツールでログイン済みであること |

> **注意：** Claude Code や Codex がインストールされていない場合、該当サービスは「未インストール」と表示されます。インストール・ログイン済みのサービスだけ表示されます。

## 3. インストール・起動方法

### インストール

インストール作業は不要です。`TokenChecker.exe` を任意のフォルダに置くだけで使えます。

```
推奨の配置場所（例）:
C:\Tools\TokenChecker\TokenChecker.exe
```

### 起動

`TokenChecker.exe` をダブルクリックすると起動します。

- 起動直後はタスクバー右下のトレイ領域にアイコンが表示されます
- 最初のデータ取得まで数秒かかります（アイコンが暗い状態は取得中です）

### 終了

タスクバーのトレイアイコンを右クリックして「**終了**」を選択してください。

## 4. 基本的な使い方

### トレイアイコンの操作

タスクバー右下のトレイアイコンをクリックまたは右クリックすると操作メニューが表示されます。

```
┌─────────────────────┐
│ ✔ 使用率を確認      │  ← クリックでポップアップを開く
│   今すぐ更新        │  ← データを手動で最新化する
│   設定              │  ← 各種設定を変更する
│ ─────────────────── │
│   終了              │  ← ツールを終了する
└─────────────────────┘
```

### アイコンの色の意味

| 色 | 残量 |
|----|------|
| 緑 | 30% 以上 |
| オレンジ | 10〜30% |
| 赤 | 10% 未満（残量わずか） |

## 5. ポップアップ画面の見方

「**使用率を確認**」をクリックすると、詳細情報のポップアップが画面右下に表示されます。

```
┌─────────────────────────────────────────┐
│ 🔢  Token Checker                        │
├─────────────────────────────────────────┤
│ Claude Code                             │
│   5時間ウィンドウ  [████████░░]  残り65.0%  │
│     1,200 / 3,500     ⏱ 2時間30分後     │
│   週次ウィンドウ   [████░░░░░░]  残り45.0%  │
│                                         │
│ ─────────────────────────────────────── │
│                                         │
│ Codex                                   │
│   5時間ウィンドウ  [██░░░░░░░░]  残り20.0%  │
│   週次ウィンドウ   [████████░░]  残り80.0%  │
│                                         │
├─────────────────────────────────────────┤
│ 最終更新: 2026-06-02 14:30:00           │
│               ⚙設定  🔄更新  📋ログ  ✕閉じる │
└─────────────────────────────────────────┘
```

### 各項目の説明

| 項目 | 説明 |
|------|------|
| **5時間ウィンドウ** | 直近5時間の使用率（短期制限） |
| **週次ウィンドウ** | 今週の累計使用率（長期制限） |
| **残り〇〇%** | 現在の残量。低いほど使い込んでいる |
| **〇〇 / 〇〇** | 使用済みトークン数 / 上限トークン数 |
| **⏱ 〇〇後** | ウィンドウがリセットされるまでの時間 |
| **未インストール** | そのサービスが未ログインまたは未インストール |

### ボタンの説明

| ボタン | 動作 |
|--------|------|
| ⚙ 設定 | 設定画面を開く |
| 🔄 更新 | データを今すぐ最新化する |
| 📋 ログ | デバッグ用のJSONデータをクリップボードにコピーする |
| ✕ 閉じる | ポップアップを閉じる（ツールは終了しない） |

## 6. 設定画面の使い方

「**設定**」を選択すると設定画面が開きます。

### 更新間隔

自動更新の頻度を選択できます。

| 選択肢 | 説明 |
|--------|------|
| 1分 | 使用量の変化を細かく追いたい場合 |
| **5分**（初期値） | 通常利用にはこれで十分 |
| 15分 | バックグラウンド動作を最小限にしたい場合 |
| 30分 | 大まかな確認だけしたい場合 |

### 残量アラート

残量がここで設定した値を下回ったときにアラート通知が届きます。

- 複数選択可能（例：20% と 10% の両方にチェック）
- 残量が回復（閾値＋5% 超）したら、次回また通知されます

### スタートアップ

「**Windows 起動時に自動的に起動する**」にチェックを入れると、PC 起動時に自動で Token Checker が起動します。

> 毎回手動で起動する手間を省きたい場合はオンにしておくことをお勧めします。

### 認証ファイルのパス

通常は空欄のままで問題ありません。自動でファイルを検索します。

認証ファイルをデフォルト以外の場所に保存している場合のみ、ファイルパスを手動で指定してください。

- **Claude** 欄：Claude Code の認証ファイル（`credentials.json`）のパス
- **Codex** 欄：Codex の認証ファイル（`auth.json`）のパス
- 📂ボタンをクリックするとファイル選択ダイアログが開きます

設定が完了したら「**✓ 保存**」をクリックしてください。

## 7. トースト通知について

設定した残量閾値を下回ると、画面右下にトースト通知が表示されます。

```
┌──────────────────────────────┐
│ ⚠ Claude 残量警告            │
│ 5時間ウィンドウの残量が      │
│ 18.5% です（閾値: 20%）      │
└──────────────────────────────┘
          ← 約6秒後に自動で消えます
```

通知は以下のタイミングでリセットされ、再び通知されます：
- ウィンドウがリセットされて残量が回復したとき
- 設定した閾値より5%以上残量が増えたとき

## 8. 安全性について

Token Checker は、Claude Code / Codex の使用状況を確認するため、ローカルPC内の認証ファイルを読み取ります。

読み取り候補:

- Claude Code: `.claude` 配下の認証ファイル
- Codex: `.codex\auth.json`

読み取った認証情報は、Claude / Codex の使用状況確認APIへ問い合わせるために使います。

通信先:

- `api.anthropic.com`
- `chatgpt.com`

このツールは、認証トークン本体を画面に表示したり、ログに保存したりする目的のものではありません。
また、ユーザーファイルの削除や任意コマンドの実行を行うツールではありません。

ログファイルには、動作確認のために以下のような情報が記録されます。

- 起動時刻
- API取得結果のステータスコード
- 認証ファイルの読み取り可否
- 取得データのキー名
- エラー内容

> 本ツールは Claude Code / Codex の公式ツールではありません。各サービス側の仕様変更により、予告なく動作しなくなる可能性があります。

## 9. よくある質問・トラブルシューティング

### Q. 「未インストール」と表示される

**A.** 対象サービスの認証ファイルが見つからない状態です。以下を確認してください。

1. Claude Code または Codex がインストールされているか
2. ツールを使って**ログイン済みか**（インストールしただけではログイン状態になりません）
3. 認証ファイルを別の場所に移動していないか

それでも解消しない場合は、設定画面の「認証ファイルのパス」で手動指定をお試しください。

---

### Q. 「⚠ HTTP 401」や「⚠ HTTP 403」エラーが表示される

**A.** 認証トークンの期限切れが考えられます。Claude Code または Codex を起動して再ログインしてから、Token Checker の「🔄 更新」ボタンを押してください。

---

### Q. 「⚠ タイムアウト」と表示される

**A.** ネットワーク接続を確認してください。インターネットに接続した状態で「🔄 更新」を押すと解消されることがあります。

---

### Q. アラート通知が届かない

**A.** 以下を確認してください。

1. 設定画面で閾値にチェックが入っているか
2. 現在の残量が設定した閾値以下になっているか
3. すでに通知済みの場合は、残量が回復（閾値＋5%超）するまで次の通知は来ません

---

### Q. アイコンが暗いままで変わらない

**A.** 起動直後はデータ取得中のため数秒かかります。しばらく待っても変わらない場合は「今すぐ更新」を試してください。

---

### Q. 同時に複数のウィンドウが表示されている

**A.** Token Checker を複数回起動している可能性があります。タスクマネージャーで重複しているプロセスを終了し、1つだけ起動してください。

---

### Q. タスクマネージャーに `TokenChecker.exe (2)` と表示される

**A.** 配布形式の都合で、タスクマネージャー上では `TokenChecker.exe (2)` のように表示される場合があります。

トレイアイコンが1つだけ表示され、設定画面や通知が1つだけ動いていれば正常です。

すでに起動している状態で再度起動しようとした場合は、多重起動防止によりメッセージが表示され、追加起動されません。

---

### Q. ログファイルはどこにありますか？

**A.** `TokenChecker.exe` と同じフォルダに `token_checker.log` というファイルが自動生成されます。動作の記録が保存されているので、問題が起きた際に確認できます。
